# TooburDialCanvas
Watch face editor for the TOOBUR IDW20 Smartwatch

> **Warning:** Before creating or sideloading custom watch faces, please be aware that this may void the device's warranty and could potentially damage it, or in rare cases, a boot-loop. Always backup your app-cached watch faces before using this editor. Use at your own risk.

## Features
- Create and edit watch faces for the TOOBUR IDW20 Smartwatch
- Preview watch faces in real-time
- Raw iwf.json (IDO Watch Face Configuration) file editing
- And more...

## Installation
1. Ensure you have Python 3.10 or higher installed on your system.
2. Clone the repository or download the source code.
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Navigate to the project directory and the src folder:
   ```bash
   cd TooburDialCanvas
   ```
5. Run the application:
   ```bash
   python main.py
   ```
